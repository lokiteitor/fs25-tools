Controles & Guía de Uso

Edición de Terreno (DEM):

  • Selecciona una herramienta (Elevar, Bajar, Aplanar, Suavizar) en la barra lateral.
  • Haz clic izquierdo y arrastra en el Editor 2D central para pintar alturas.
  • Usa la Herramienta Rampa haciendo clic en "Fijar Inicio" y "Fijar Fin", define los parámetros y presiona "Aplicar Rampa".

Edición Vectorial (OSM):

  • Editar Nodos: Haz clic sobre cualquier nodo (círculo) en el mapa para seleccionarlo y arrástralo para reposicionarlo. Selecciona un nodo y presiona Supr / Del para borrarlo.
  • Crear Way: Haz clic sucesivo sobre el mapa para colocar los nodos. Presiona Enter para cerrar/terminar el trazado del polígono/línea, o Escape para cancelar.
  • Las formas se proyectan automáticamente en la visualización 3D.

Navegación 3D:

  • Arrastra con el botón izquierdo para rotar la cámara.
  • Arrastra con el botón derecho para desplazar la vista (paneo).
  • Usa la rueda del ratón para hacer zoom.
